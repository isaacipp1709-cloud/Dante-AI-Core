## 🚀 Despliegue Rápido (LibreChat & Hugging Face)

1. **Configuración LibreChat:**
   * Monta el archivo `librechat.yaml` en la raíz de tu servidor LibreChat.
   * El preset `dante-v4-superhumano` inyectará automáticamente el System Prompt Maestro y los parámetros base (`temperature: 0.2`, `topP: 0.95`).
   * Configura tu API Key de Google (Gemini 1.5 Pro) en tu entorno.

2. **Hugging Face / Inferencia Zero-Cost:**
   * Integra `dante_runtime_orchestrator.js` como middleware (sandbox) antes y después de cada llamada a tu LLM para mitigar alucinaciones y ejecutar el **RAG Shield**.
   * Indexa el directorio `neurons/` utilizando el Reranking en herradura para maximizar el contexto retenido.
