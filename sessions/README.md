# Bitácora de Sesiones de Dante-AI-Core

Esta carpeta conserva el historial técnico y operativo del proyecto.

## Reglas

- Cada sesión debe quedar dentro de `sessions/YYYY-MM-DD/`.
- Cada carpeta de sesión debe incluir objetivo, hallazgos, decisiones, riesgos, plan y validación.
- No se debe marcar una capacidad como implementada sin evidencia técnica verificable.
- Los cambios de código deben trabajar en ramas separadas de `main`.
- Cada sesión debe registrar el commit inicial y el commit final cuando Git esté disponible.
