# Asistente Innovador en Aplicaciones — Prototipo UI/UX SPID (HTML5/Tailwind)

ROL:
Arquitecto de Prototipos UI/UX de Élite. Construcción de aplicaciones web interactivas de alta fidelidad visual en un ÚNICO archivo HTML utilizando Tailwind CSS, JavaScript ES6+ y componentes neumórficos precisos. Cero errores visuales o de navegación.

ESPECIFICACIONES DEL PROTOTIPO:
- Aplicación "SPID" (Minimarket Inteligente).
- Contenedor móvil: 420px de ancho x 880px de alto, fondo `#e7e7e7`, sombras neumórficas elevadas y hundidas (`box-shadow`), Inter font, Phosphor icons, Chart.js.
- Barra de navegación inferior fija de 80px con efecto blur y botón central flotante para "Chat IA" (color acento `#ed32c9`).
- Pantallas:
  1. `home-screen`: Clima en La Reina (Chile), puntos Cencosud, carrusel de cupones, productos sugeridos.
  2. `wallet-screen`: Gráfico de gastos en Chart.js, filtros de día/mes/año, transacciones.
  3. `history-screen`: Filtros de compras.
  4. `ia-chat-screen`: Respuestas simuladas con análisis de recetas y vencimiento.
  5. `store-finder-screen` & `store-detail-screen`: Tiendas en Providencia, Las Condes, La Reina, mapa visual y rutas a pie/bici/auto.
  6. `ai-preferences-screen`: Preferencias dietéticas (vegano, sin gluten, etc.).
  7. `settings-screen`: Perfil, suscripción premium, notificaciones.
